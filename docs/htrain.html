폰에 설치 안드로이드 · 약 2MB PC에 설치 윈도우 · 약 26MB

둘 다 쓰셔도 됩니다. 폰과 PC 중 켜져 있는 쪽이 표를 찾습니다.

폰에 까는 법

처음 한 번만 조금 번거롭습니다. 다음부터는 앱이 알아서 새 버전을 받습니다. 중간에 경고처럼 보이는 창이 몇 개 뜨는데, 어떤 창이 어떤 순서로 뜨는지 아래에 그대로 적어두었습니다. 그대로만 누르시면 됩니다.

  1. 위의 폰에 설치 를 누릅니다 폰에서 이 페이지를 열고 누르셔야 합니다. PC에서 누르면 PC로 받아집니다.
  2. “이런 종류의 파일은 기기에 위험할 수 있습니다” 다운로드 를 누르세요. 인터넷에서 받는 앱이라 브라우저가 늘 하는 말입니다.
  3. 받은 파일을 엽니다 화면 위에서 아래로 쓸어내리면 htrain-app.apk 가 보입니다. 그것을 누르세요.
  4. “이 출처의 앱 설치” 를 허용합니다 설정 화면으로 넘어갑니다. 이 출처 허용 스위치를 켜고, 뒤로 가기를 누르면 아까 자리로 돌아옵니다. 한 번만 하면 됩니다.
  5. “Google Play 프로텍트” 가 검사하겠다고 합니다 앱 검사 를 누르세요. 잠시 뒤 “안전한 앱으로 판단됨” 이 나오면 설치 를 누릅니다.
  6. 앱을 열고 로그인합니다 받으신 아이디와 비밀번호를 넣으세요.
  7. “시작하기 전에” 세 가지를 켭니다 알림 허용 · 절전 예외 · 업데이트 설치 허용 — 각 항목의 허용하기 를 눌러 셋 다 체크가 되게 해주세요. 이걸 안 하면 화면을 끄고 몇 시간 뒤 앱이 조용히 멈춥니다.
삼성 폰에서 “Auto Blocker” 가 막는다면
설정 → 보안 및 개인정보 보호 → Auto Blocker 에서 꺼주세요. 최신 갤럭시는 이것이 켜져 있으면 위 4번 화면이 아예 나타나지 않습니다.
왜 이런 창이 뜨나요?
플레이스토어에 올리지 않고 직접 나눠 쓰는 앱이라 그렇습니다. 만든 사람이 확실하고(같은 서명), 구글 검사도 통과합니다. 번거로운 건 처음 한 번뿐입니다.

PC에 까는 법

폰보다 간단합니다. 관리자 권한도 필요 없습니다.

  1. 위의 PC에 설치 를 누릅니다 브라우저가 “일반적으로 다운로드되지 않는 파일” 이라고 하면 유지 를 누르세요.
  2. 받은 파일을 두 번 누릅니다 HTrain_Personal_Setup.exe
  3. “Windows의 PC 보호” 가 뜨면 추가 정보 를 누른 다음 실행 을 누르세요. 많이 퍼지지 않은 프로그램이라 윈도우가 하는 말입니다.
  4. 설치가 끝나면 저절로 켜집니다 바탕화면에도 아이콘이 생깁니다. 로그인하시면 됩니다.
PC는 켜두기만 하면 됩니다
컴퓨터를 켤 때 자동으로 같이 켜지고, 창을 닫아도 뒤에서 계속 표를 찾습니다. 자리를 잡으면 알림이 옵니다.

다음부터는 알아서 됩니다

새 버전이 나오면 켤 때 앱이 스스로 받아서 깝니다. 이 페이지에 다시 오실 일은 없습니다.

폰에서만, 새 버전을 깔 때마다 Google Play 프로텍트 창이 한 번 더 뜹니다. 앱 검사 → 설치 두 번만 눌러주세요. 구글이 처음 보는 파일을 늘 검사하기 때문이라, 없앨 수가 없습니다.

잘 안 될 때

“업데이트가 필요합니다” 에서 안 넘어갈 때
그 화면의 설치 허용 켜기 를 누르고 스위치를 켜주세요. 그래도 안 되면 브라우저로 받기 를 누르면 이 페이지로 옵니다.
“앱이 설치되지 않았습니다” 가 뜰 때
예전 앱을 지우고 다시 깔아주세요. 로그인만 다시 하시면 됩니다.
그래도 안 되면
어떤 화면에서 막혔는지 사진을 찍어 알려주세요. 그게 제일 빠릅니다.
